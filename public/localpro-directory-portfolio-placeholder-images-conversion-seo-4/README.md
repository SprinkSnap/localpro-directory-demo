# LocalPro Directory portfolio-placeholder image pack

This conversion- and SEO-oriented pack replaces every portfolio placeholder currently exposed by the seeded directory: **435 images across 177 “Portfolio available” listings**. Existing custom portfolio imagery and zero-image listings were left untouched.

## Included

- 435 self-contained 1200×900 SVG files in `images/`
- 72 optimized category-and-service gallery masters in `gallery-masters/`
- JSON, CSV and TypeScript integration maps in exact portfolio order
- Unique, lowercase, keyword-relevant filenames
- Recommended HTML alt text plus SVG `<title>`, `<desc>` and Dublin Core metadata

## Recommended integration

1. Copy `images/*.svg` into `public/images/`.
2. Use `portfolio-image-map.ts` or `portfolio-image-map.json` to replace each provider's placeholder array in the supplied order.
3. Reuse the supplied alt text in the page's HTML `alt` attribute.
4. Keep width and height attributes at 1200 and 900 to prevent layout shift.
5. Preserve the fictional-concept disclosure near every gallery.

## Scope

- Included: listings whose portfolio currently points to `/images/portfolio-placeholder.svg`.
- Preserved: five listings with custom portfolio imagery.
- Excluded: 238 listings with no portfolio slots; they belong to the separate zero-image package.
